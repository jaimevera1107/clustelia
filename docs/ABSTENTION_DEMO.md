# Does Clustelia actually abstain?

Generated by `python examples/abstention_demo.py --markdown` with clustelia 0.2.0, seed 0, default `cluster()` settings. Re-run it to reproduce every number below.

A clustering library that can only ever return clusters is easy to write. The claim worth checking is the opposite one: that this search says *no* when the data has no groups, and still says *yes* when it does.

| Dataset | Null reference | Structure test | Decision | Clusters | Fits | Time |
|:--|:--|:--|:--|--:|--:|--:|
| Pure noise | pca_uniform | **failed** | `no_admissible_solution` | — | 42 | 0.6 s |
| Three separated blobs | pca_uniform | passed | `recommended` | 3 | 246 | 2.7 s |
| Skewed cloud, default reference | pca_uniform | passed | `recommended` | 2 | 246 | 2.5 s |
| Skewed cloud, copula reference | gaussian_copula | **failed** | `no_admissible_solution` | — | 42 | 0.5 s |

## What each row shows

- **Pure noise.** Are there groups in one Gaussian cloud? Decision: `no_admissible_solution` — no groups exist, so abstention is correct (as documented).
- **Three separated blobs.** Are there groups when there are? Decision: `recommended` — three groups exist and are recovered (as documented).
- **Skewed cloud, default reference.** Is a skewed single mode mistaken for groups? Decision: `recommended` — KNOWN FAILURE: no groups exist, yet the uniform-box reference is beaten by the skew (as documented).
- **Skewed cloud, copula reference.** Does the experimental reference fix it? Decision: `no_admissible_solution` — same data, marginal-preserving reference, no groups reported (as documented).

Rows 1 and 2 are the two sides of the decision: the same search, the same
settings, opposite answers. Row 1 costs far fewer fits than row 2 because
a failed structure test ends the search before any confirmation fit is
spent.

Rows 3 and 4 are the honest part, and row 3 is a failure reproduced on
purpose. A single lognormal cloud has no groups, but it is skewed, and
the default uniform-box reference reads that skew as structure often
enough to matter: across 30 seeds it recommended a partition in 17 to 20
of 30 such datasets. The experimental
`gaussian_copula` reference preserves every marginal and the rank
correlation, and recommended in 0 to 1 of 30, while still detecting 29 to
30 of 30 real three-group mixtures. One seed is an illustration, not
evidence; the 600-search study behind those rates, with Wilson intervals
and the decision to keep `pca_uniform` as the default, is in
[VALIDATION.md](VALIDATION.md).

## Reading this honestly

The structure test is a screening rule, not a proof. It compares your
data with references built from your own data, so its nominal resolution
(`1 / (null_replicates + 1)`) is not a calibrated false-positive rate.
What these four rows do show is that the decision is real: the same
pipeline reaches opposite verdicts on data that differs only in whether
groups exist.
